1. Read the configuration: templates and rules, controls, document types, custom properties, portals, enabled check types, AI review and policy settings. 2. Compare against what the workspace actually does — which check types are used, which templates applied, which portals get traffic. 3. Report three lists: configured but never used, used but misconfigured, switched off while clearly needed. 4. Rank by what it costs today, with the number behind each. 5. Never recommend enabling something with a cost or regulatory implication without naming it.
